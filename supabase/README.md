# Supabase Миграции (Unique Agency Manager)

## 🗄️ Миграция `001_erp_system_init.sql`

**Назначение:**
Этот SQL-скрипт подготавливает базу данных для работы Фазы 5 (Глобальное ERP-обновление). Он добавляет модуль управления сотрудниками, Планировщик (Канбан-доску задач) и расширяет возможности управления заказами (Исполнитель, Привлекатель, Заметки). 
*(Мультивалютность реализована на стороне клиента и не требует изменений в БД на этом этапе).*

**Что именно добавляет скрипт:**
1. **Таблица `employees`**: Для хранения списка сотрудников агентства. Поля: `full_name`, `role`, `status`.
2. **Таблица `tasks`**: Для работы Канбан-планировщика. Поля: `title`, `stage` (этап на доске), `order_id` (привязка к заказу), `executor_id` (кто выполняет).
3. **Обновление таблицы `orders`**: Добавлены 3 новые колонки (`executor_id`, `finder_id`, `notes`) для хранения ответственных лиц и комментариев по сделке.

## 🗄️ Миграция `006_finance_and_salary.sql`

**Назначение:**
Добавляет поддержку Продвинутого финансового модуля (Фаза 6): учет предоплат и долгов по заказам, балансы сотрудников (зарплаты и авансы), а также систему категорий для расходов.

**Что именно добавляет скрипт:**
1. **Обновление `orders`**: Добавляет колонки `prepayment` (предоплата), `executor_amount` (заработок исполнителя) и `finder_amount` (заработок Finder-а).
2. **Обновление `transactions`**: Добавляет `employee_id` для привязки авансов и выплат к конкретным сотрудникам.
3. **Таблица `expense_categories`**: Создает таблицу категорий расходов и заполняет её базовыми значениями (Маркетинг, Офис, Зарплаты и Авансы и т.д.).

## 🚀 Как применить миграции

Выполните следующие шаги в панели управления Supabase:

1. Зайдите в ваш проект на сайте **Supabase**.
2. В левом меню выберите раздел **SQL Editor** (иконка консоли).
3. Нажмите кнопку **New Query** (Новый запрос).
4. Скопируйте всё содержимое файла `supabase/migrations/001_erp_system_init.sql`.
5. Вставьте код в открывшееся окно редактора.
6. В правом нижнем углу выберите **Run without RLS** (Запустить без RLS). *Это важно для корректной работы MVP-клиента без сложной системы токенов авторизации.*
7. Дождитесь появления зеленой надписи **"Success"**. База данных успешно обновлена!
