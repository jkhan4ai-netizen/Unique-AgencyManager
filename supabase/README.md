# Инструкции по базе данных Supabase

В этой директории (`supabase/migrations/`) хранятся SQL-миграции базы данных. Каждая миграция — это шаг развития нашей базы. Они нумеруются по порядку (`001`, `002` и т.д.), чтобы мы могли последовательно применять изменения архитектуры.

## Описание Миграций

### `001_erp_system_init.sql` (Фаза 5 Обновления)
**Цель миграции:** Обновление MVP-проекта до уровня полноценной ERP-системы.
**Что добавляет:**
1. **Сотрудники**: Создает таблицу `employees` для хранения списка команды и ролей.
2. **Планировщик (Kanban)**: Создает таблицу `tasks`, которая хранит задачи с привязкой к этапам производства (`stage`) и привязкой к заказам (`order_id`).
3. **Модернизация Заказов**: Добавляет новые колонки `executor_id`, `finder_id` и `notes` в существующую таблицу `orders` для назначения людей и хранения заметок.

## 🛠 Пошаговая инструкция: Как применить эти миграции

Чтобы обновить вашу базу данных на Supabase, следуйте этой инструкции:

1. Откройте ваш проект в панели управления [Supabase](https://supabase.com/dashboard/).
2. Перейдите в раздел **SQL Editor** (иконка консоли в левом меню).
3. Нажмите на кнопку **New query** (или **+**), чтобы создать новый скрипт.
4. Скопируйте всё содержимое нужного файла миграции (например, `001_erp_system_init.sql`) и вставьте в редактор Supabase.
5. Нажмите кнопку **Run** (Запустить) в правом нижнем углу.
   - *Примечание: Если система спросит "Run without RLS", обязательно выбирайте этот вариант, так как наше MVP работает без строгих политик безопасности на уровне строк.*
6. Готово! Вы увидите сообщение об успешном выполнении запроса, и в разделе **Table Editor** появятся новые таблицы.
